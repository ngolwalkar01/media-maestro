Media Maestro brings AI-powered image generation, image editing, and media organization directly into the WordPress Media Library.

== Description ==

Media Maestro transforms the WordPress Media Library into an AI-powered creative workspace. Generate brand-new images, modify existing ones, and organize your media with folders—all without leaving the WordPress dashboard.

Whether you're a blogger, designer, marketer, or business owner, Media Maestro helps you create and manage images faster using simple text prompts.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure your AI provider/API credentials if required.
4. Open **Media → Library** to start generating, editing, and organizing your media.

== Frequently Asked Questions ==

= Does Media Maestro replace the default Media Library? =

No. Media Maestro extends the existing WordPress Media Library while preserving the native experience.

= Where are generated images stored? =

All generated images are saved directly into your WordPress Media Library.

= Do folders create physical directories on the server? =

No. Media Maestro uses virtual folders for organizing media without moving or renaming your actual files.

= Can I organize existing media? =

Yes. Existing images and videos can be dragged into folders at any time.

= Can I edit existing images? =

Yes. Simply select an image and use an AI prompt to create a modified version.

= Will deleting a folder delete my images? =

No. Deleting a folder only removes the folder. Your media files remain safely in the Media Library.
